Stripe API Field Reference

How this panel maps to the Stripe API · GET /v1/subscriptions + GET /v1/customers

Subscription fields: subscription.status (trialing · active · past_due · canceled · paused · unpaid), subscription.trial_end, subscription.current_period_end (next billing), subscription.canceled_at, subscription.cancellation_details.reason, subscription.cancel_at_period_end (cancelling at period end), subscription.items.data[0].price.nickname (plan name), subscription.items.data[0].price.unit_amount (price in cents → MRR).

Customer fields: customer.id, customer.name, customer.email, customer.created (Unix timestamp), customer.metadata.company.

Azure-stored fields (not in Stripe): xero_connected (bool), token_usage (int), token_limit (int), last_login (ISO date). Joined to Stripe customer via customer.id.
LXI Accountant AI admin uses Azure as the app data backend (AI processing, token usage, Xero connection state) and Stripe as the billing source (subscriptions, plans, trial status). Configure both endpoints below. Values are stored in localStorage for this device — use Azure Key Vault for production secrets.
