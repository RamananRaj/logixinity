Stripe Integration

How revenue data maps to Stripe API fields

Subscription fields: subscription.status (trialing · active · past_due · canceled · paused), subscription.current_period_end (next billing), subscription.canceled_at, subscription.items.data[0].price.nickname (plan name), subscription.items.data[0].price.unit_amount (price in cents → MRR).

Customer fields: customer.name, customer.email, customer.created, customer.metadata.company.

Azure-stored fields: xero_connected, token_usage, token_limit, last_login. Enter your Stripe secret key and Azure endpoint in Settings to go live.

Blog Database Setup

Run this SQL once in Supabase → SQL Editor to create the blog_posts table.

CREATE TABLE IF NOT EXISTS blog_posts (
  id          uuid        DEFAULT gen_random_uuid() PRIMARY KEY,
  title       text        NOT NULL,
  content     text        NOT NULL DEFAULT '',
  cover_image text,
  author      text,
  publish_date date,
  tags        text,
  published   boolean     DEFAULT false,
  created_at  timestamptz DEFAULT now(),
  updated_at  timestamptz DEFAULT now()
);
ALTER TABLE blog_posts ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Public read published" ON blog_posts FOR SELECT USING (published = true);
CREATE POLICY "Anon full access" ON blog_posts FOR ALL USING (true) WITH CHECK (true);
